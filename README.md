# Adithya V - Personal Portfolio Website

A modern, responsive personal portfolio website for **Adithya V** (B.Tech in Artificial Intelligence & Data Science at REVA University).

## 🚀 Live Preview & Features
- **Modern Glassmorphic UI**: Ambient particle canvas animations, futuristic dark aesthetic with light/dark theme switcher.
- **Dynamic Typing Effect**: Interactive introduction showcasing skills and aspirations.
- **Academic Highlights**: Coursework details, current CGPA (8.78), and educational timeline at REVA University.
- **Interactive 2D Graphics Editor Simulator**: A live virtual terminal widget simulating the C-based 2D character-array graphics editor.
- **Featured Projects**:
  - **Skin Cancer Detection using ESP32-CAM** (IoT, OpenCV, TensorFlow Lite)
  - **2D Graphics Editor** (C, 2D Character Array, Windows Console API)
  - **AquaSmart** (HTML5, CSS3 Responsive UI)
- **Verified Credentials**: IBM Data Analysis with Python (`DA0101EN`) & Wadhwani Foundation Ignite Full.
- **Connect & Contact**: One-click email copy to clipboard, direct links to LinkedIn & GitHub, and interactive contact form.

## 🛠️ Built With
- **HTML5**: Semantic and accessible document structure with OpenGraph meta tags.
- **Vanilla CSS3**: CSS custom properties, responsive grid/flexbox layouts, glassmorphism, animations.
- **JavaScript (ES6+)**: Particle animations, theme toggler, skill filters, terminal simulator, and toast notification system.
- **FontAwesome 6 & Google Fonts**: Plus Jakarta Sans, Outfit, and JetBrains Mono.
