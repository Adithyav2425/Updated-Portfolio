Skin Cancer Detection using ESP32-CAM

An AI-powered edge screening system integrating an ESP32-CAM microcontroller module to capture real-time skin lesion images. The pipeline utilizes OpenCV for automated image preprocessing and contrast enhancement, followed by a TensorFlow / TensorFlow Lite machine learning model to analyze and classify lesions as normal or suspicious.

Key Contribution: Architected the hardware-to-software image acquisition stream via ESP32-CAM, implemented OpenCV preprocessing filters in Python, and integrated TensorFlow Lite inference for lightweight preliminary lesion screening.
  • Low-cost, portable preliminary diagnostic tool
  • Edge IoT camera integration with real-time capture
  • OpenCV image enhancement & lesion segmentation
  • TensorFlow / TF Lite classification model

2D Graphics Editor (C & Console API)

A menu-driven 2D Graphics Editor engineered in C using a 60 × 25 character-array virtual canvas. Designed with low-level matrix memory manipulation and Windows Console API for interactive rendering, shape generation, state persistence, and canvas clearing.

  • 60 × 25 character-array dynamic 2D canvas
  • 4 Geometric shapes: Rectangle, Circle, Line, Box
  • Interactive Drawing, Erasing, and Clear Canvas
  • File save & state buffer export functionality
  • Menu-driven console UI via Windows API
